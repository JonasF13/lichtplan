# Lichtplan

Foto-Planungs-App für Sonne, Mond und Milchstraße: Projekte, Spots und Termine,
Street View mit Sonnenbahn, Ausrichtungs-Planer, Wetter und KI-Assistent.

Alle persönlichen Daten bleiben im Browser des Nutzers bzw. in seinem privaten Sync-Repository.
Bibliotheken: Leaflet (BSD-2), astronomy-engine (MIT), qrcode-generator (MIT).
